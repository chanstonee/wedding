# 히어로 커플 SVG 모션

## 원본과 보존 범위

원본 `public/assets/invitation/section-0-img.svg`는 326 × 272.315 viewBox,
2개 그룹/314개 path의 벡터이며 raster 이미지는 없습니다. 저장소 SVG를 분석한
결과이며, 원본 Figma 편집 파일 자체를 확인한 것은 아닙니다.

`app/lib/hero-couple-paths.json`은 원본의 모든 경로 좌표·색상·fill-opacity·
fill-rule·clip-rule을 원래 순서대로 보존합니다. 원본 SVG 파일도 그대로 둡니다.
`HeroCouple.tsx`는 이 경로를 인라인 SVG로 렌더하며, 새 그림이나 경로를 그리지
않습니다. 클리핑에 필요한 복사 경로는 원본과 같은 d/paint 속성을 사용하며
각 DOM ID는 고유합니다. 원본 전체의 0.8 opacity와 별의 별도 opacity도 유지합니다.

## SVG 및 래퍼

```tsx
<div className="inv-couple">
  <HeroCouple />
</div>
```

SVG는 공통 float/sway 아래에 Male/Female을 두고, Female 내부에 드레스 하단과
뒷머리 끝의 후행 그룹을 둡니다. 원래 맨 위에 그렸던 인물별 세부 경로는 원래
그리기 순서대로 별도 그룹으로 유지합니다. 하트와 별도 원본 경로를 재사용합니다.
모든 애니메이션은 `app/invitation.css`의 `.inv-couple-*`와 동명 keyframes에 있습니다.
외부 라이브러리나 JS 애니메이션 루프, MP4/GIF는 사용하지 않습니다.

## 강화된 모션

모두 ease-in-out 무한 반복이며, 기존 등장 모션 뒤에 시작합니다.

| 대상 | 동작 | 주기 / 시작 지연 |
| --- | --- | --- |
| 커플 공통 | sway ±3.5°, upward float 11 SVG 단위 | 3.8초 / 1.5초 |
| Male | 손 연결점 중심 ±0.55° counter-sway | 3.8초 / 1.5초 |
| Female | 반대 방향 ±0.9°, 남자보다 0.14초 뒤에 따라옴 | 3.8초 / 1.64초 |
| Dress | 하단 자락 전체에 ±4.5° skewX 후행 변형 | 3.8초 / 1.88초 |
| Hair | 뿌리 아래 끝부분에 ±3.5° skewX 후행 변형 | 3.8초 / 1.94초 |
| Decoration | 하트/별의 작은 1.3/0.8 단위 float 유지 | 5.2/5.6초 |

실제 float 범위는 320px/390px/480px에서 약 9.0/11.0/13.5 CSS px입니다.
남자는 공통 회전을 조금 상쇄하고 여자는 더 유연하게 따르므로 두 몸체의
각도·타이밍이 완전히 같지 않습니다. 손의 공통 pivot은 원본 좌표 `(181,24)`로,
모든 시점에서 같은 화면 위치에 남습니다.

## 드레스·머리카락의 연결 유지

원본의 몸통·팔·드레스 외곽선 일부가 같은 경로에 연결되어 있어, 경로 자체를
잘라 수정하거나 원래 전체 경로를 큰 각도로 회전시키지 않습니다. 원본 경로의
상단/하단 인스턴스를 SVG clipPath로 구분하고 하단에만 CSS skewX를 적용합니다.

- 드레스는 y=164, 머리카락은 y=93에서 나눕니다.
- skewX 변형은 해당 수평 연결선에서 변위가 0입니다. 드레스와 머리카락의
  움직임을 키워도 상단 연결점은 움직이지 않아 틈이 생기지 않습니다.
- 드레스 손잡는 부분 위 몸통과 머리·얼굴은 고정하고, 그 아래 자락/머리 끝이
  뒤늦게 흐르도록 합니다. 본체 Female 모션과 공통 스웨이는 함께 따릅니다.
- 연결선 양쪽에 0.25 단위의 작은 클리핑 중첩을 둬 안티앨리어싱 틈을 방지합니다.
- ±4.5°/±3.5°는 연결선을 유지하는 shear 각도이며, 조각 전체를 회전시키는 값이
  아닙니다. 원본 d와 색은 바꾸지 않고, 움직일 때만 하단 실루엣이 유연하게 기웁니다.

`prefers-reduced-motion: reduce`에서는 움직이는 분할 그룹을 숨기고, 클리핑 없는
원본 경로를 원래 순서로 표시합니다. 정지 그림은 원본과 픽셀 차이 0입니다.
클리핑된 움직임의 중립 자세에는 작은 래스터 경계 차이가 있으므로 정지용으로
재사용하지 않습니다. 실제 관절 굽힘·천 시뮬레이션·새 인체 레이어 재구성은 하지 않습니다.

## 검증과 미리보기

320px/390px/480px에서 각 41개 시점을 검사했습니다.

- 손 pivot의 위치 차이 0, 접촉부 주변 차이는 각각 최대 약 0.13/0.16/0.20px.
- 드레스·머리카락 연결선 변위 0. 자락 끝은 약 6.5/7.9/9.7px,
  머리 끝은 약 2.7/3.2/4px의 후행 이동을 보입니다.
- 회전·float 범위, 실제 CSS 재생과 반복 경계, 잘림·이름 겹침·가로 넘침 없음.
- 모션 감소 시 animation 0, 클리핑 없는 정지 렌더는 원본과 픽셀 차이 0.
- 갤러리 MORE/순환/닫기, BGM 연속 재생, JS/로컬 HTTP 오류 없음.
- Pages 빌드와 타입 검사, lint, 기존 및 신규 자동 테스트 통과.

검증 자료는 `/workspace/wedding-hero-motion-stronger-verification/`입니다.
`hero-couple-preview.svg`는 실제 경로와 CSS를 포함한 독립 SVG 미리보기이며,
`motion-comparison.html`에는 이전/강화 SVG를 영상 변환 없이 나란히 담았습니다.
`hero-motion.css`, 시점별 PNG/trace, `results.json`, `static-fidelity.json`,
`reduced-motion.json`, `standalone-preview.json`도 보관합니다.
실제 iOS Safari 및 실기기 FPS는 미검증입니다.
