# 공통 CTA

주요 행동 버튼은 `app/cta.css`의 한 스타일 계열을 사용합니다. `app/page.tsx`에서 섹션 CSS 다음에 로드합니다.

- `inv-cta`: 기존 브라운 본문색 `#604e4d` 채움, 아이보리 글자.
- `inv-cta inv-cta--blue`: 기존 방명록 남색 `#555e6d` 채움.
- 공통 모서리 4px, 최소 높이 48px, 패딩 12px 16px, Pretendard 16px/24px 500.
- 버튼별 부모/최대 폭과 지도 링크의 두 줄 설명 배치는 유지합니다. 기존 이중 테두리는 표시하지 않습니다.
- CTA 내부 아이콘은 CSS 필터로 밝게 표시하며 원본 에셋 파일은 변경하지 않습니다.

적용: 지도 바로가기와 지도 선택 링크, 계좌번호 복사, 참석 여부 전달, 응답 공유·내용 복사, 방명록 작성·등록·삭제·재시도.

커튼, 갤러리 사진·화살표, 아코디언, 닫기, 주소 복사 아이콘과 BGM은 탐색/토글/아이콘 컨트롤이므로 기존 형태를 유지합니다.
