# 이전 방명록 데이터베이스 기록

현재 청첩장은 Supabase를 사용하지 않습니다. 관리자 페이지와 로그인·세션 처리, 앱 연결 코드 및 빌드 환경변수 설정은 제거했습니다. 참석 여부는 기존대로 기기 공유 또는 복사로 직접 전달합니다.

이 폴더의 마이그레이션과 SQL 권한 테스트는 기존 방명록 데이터베이스의 스키마·접근 정책을 기록하기 위해 보존합니다. 앱 실행·빌드·GitHub Pages 배포에서는 사용하지 않습니다. 기존 데이터베이스가 외부에서 사용되는지는 확인하지 않았습니다.

이번 정리는 저장소의 앱 코드에만 적용했습니다. Supabase 프로젝트, 사용자, 테이블, 데이터, 운영 권한 및 GitHub에 저장된 연결값은 변경하거나 삭제하지 않았습니다. 보존된 SQL은 기존 데이터베이스에 다시 실행하지 마세요.
